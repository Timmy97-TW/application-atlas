# Application Atlas / 申請地圖

A research database and a static bilingual website (Traditional Chinese and
English) that explain, with verifiable citations, what a first-year applicant
to a US university submits, when, through which portal, and in what format —
with depth on portfolios and supplementary materials for engineering and
biology applicants, and on how a multi-year record built outside school can
enter the application.

- Site: https://timmy97-tw.github.io/application-atlas/
- Rules for contributors and automated runs: [CLAUDE.md](CLAUDE.md)
- What is being researched next: [BACKLOG.md](BACKLOG.md)
- Open questions for the maintainer: [QUESTIONS.md](QUESTIONS.md)
- Why the scope is what it is: [DECISIONS.md](DECISIONS.md)

Every factual statement carries a source URL, an access date and a source
class (official / secondary), and is tagged as fact, inference or assumption.
This is not admissions advice; the schools' and application systems' own pages
govern.
